# Assignment 6 - Environmental Clustering and ANN

## Overview

This assignment explores unsupervised learning and deep learning techniques to analyze global pollution data and predict energy recovery outcomes.

The project focuses on discovering environmental patterns using clustering algorithms and building an Artificial Neural Network (ANN) to predict energy recovery based on pollution-related factors.

## What I Did

### Data Preparation

* Cleaned and prepared the dataset
* Handled missing values
* Encoded categorical features
* Normalized pollution-related variables
* Created additional environmental indicators

### Feature Engineering

* Energy Consumption per Capita
* Pollution Severity Categories
* Pollution Trend Analysis
* Environmental Feature Scaling

### Clustering Analysis

Implemented and compared:

* K-Means Clustering
* Hierarchical Clustering (Agglomerative Clustering)

#### Clustering Evaluation

* Elbow Method
* Cluster Visualization
* Dendrogram Analysis
* Cluster Comparison

### Neural Network Development

Built an Artificial Neural Network (ANN) using:

* Input Layer
* Hidden Layers
* Output Layer for Energy Recovery Prediction

### Model Improvement

Experimented with:

* Number of Hidden Layers
* Number of Neurons
* Learning Rates
* Activation Functions
* Training Epochs

### Model Evaluation

Evaluated performance using:

* R² Score
* Mean Squared Error (MSE)
* Mean Absolute Error (MAE)
