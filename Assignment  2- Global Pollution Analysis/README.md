# Assignment 2 - Global Pollution Analysis

## Overview
This project explores global environmental and economic indicators using data analysis, visualization, and machine learning techniques. The objective was to identify pollution patterns, analyze relationships between environmental factors, and build predictive models for Energy Recovery and Pollution Levels.

## Dataset Features
- Air Pollution Index
- Water Pollution Index
- Soil Pollution Index
- Industrial Waste
- CO₂ Emissions
- Renewable Energy
- Energy Recovery
- Population
- GDP per Capita
- Energy Consumption Per Capita

## Concepts Used
- Data Cleaning & Preprocessing
- Label Encoding
- Feature Scaling
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Correlation Analysis
- Data Visualization
- Linear Regression
- Logistic Regression

## Visualizations
- Correlation Heatmap
- Pollution Trends Over Time
- Top 10 Countries by Pollution Score
- Pollution Distribution (Box Plot)
- Energy Consumption Trend Analysis

## Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Key Learning Outcomes
- Analyzed environmental datasets using EDA techniques.
- Created meaningful visualizations to identify trends and patterns.
- Applied regression and classification algorithms.
- Evaluated model performance using appropriate metrics.
- Generated insights and recommendations based on data analysis.

## Results
- Linear Regression struggled to predict Energy Recovery accurately.
- Logistic Regression achieved moderate classification performance for pollution categories.
- Analysis revealed weak correlations between Energy Recovery and most environmental indicators.

## Limitations
The dataset contained only 200 records, which limited the ability of machine learning models to learn complex patterns. Additionally, weak relationships between features and target variables affected predictive performance. Future improvements could include larger datasets, additional environmental factors, and advanced machine learning algorithms.

## Future Improvements
- Increase dataset size.
- Apply Random Forest and Gradient Boosting models.
- Perform advanced feature engineering.
- Explore non-linear relationships within the data.
