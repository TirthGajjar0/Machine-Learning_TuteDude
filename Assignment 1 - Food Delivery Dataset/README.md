# Assignment 1 - Food Delivery Time Prediction

## Overview
This project applies Machine Learning techniques to analyze food delivery operations and predict delivery outcomes. Two models were developed:

- Linear Regression for predicting delivery time.
- Logistic Regression for classifying deliveries as Fast or Delayed.

## Dataset Features
- Distance
- Traffic Conditions
- Weather Conditions
- Vehicle Type
- Delivery Person Experience
- Order Priority
- Delivery Time

## Concepts Used
- Data Preprocessing
- Label Encoding
- Feature Scaling
- Feature Engineering
- Exploratory Data Analysis (EDA)
- Linear Regression
- Logistic Regression
- Model Evaluation

## Libraries Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Limitations
The dataset contained only 200 records, which limited the model's ability to learn complex patterns. Additionally, some factors that significantly influence delivery time may not have been included in the dataset. As a result, model performance was moderate, particularly for Linear Regression.

Future improvements could include:
- Using a larger dataset
- Adding more relevant features
- Trying advanced models such as Random Forest or XGBoost
- Performing hyperparameter tuning
  
## Key Learning Outcomes
- For better model performance more data is needed
- Handling and preprocessing real-world datasets
- Training regression and classification models
- Evaluating model performance using different metrics
- Generating business insights from machine learning results

## Results
The Logistic Regression model achieved better performance for this dataset, but more data would help in better prediction
