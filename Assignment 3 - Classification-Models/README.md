# Assignment 3 - Classification Models (Naive Bayes, K-Nearest Neighbors (KNN), Decision Tree)

## Overview

This assignment focuses on predicting whether a food delivery will be Fast or Delayed using machine learning classification algorithms.

The project covers the complete classification workflow, from data preprocessing and feature engineering to model training, tuning, and evaluation.

## What I Did

### Data Preparation
- Cleaned and prepared the dataset
- Encoded categorical features
- Normalized numerical features
- Handled missing values

### Feature Engineering
- Calculated delivery distance using customer and restaurant coordinates
- Created delivery status categories (Fast / Delayed)

### Machine Learning Models
Implemented and compared:

- Naive Bayes
- K-Nearest Neighbors (KNN)
- Decision Tree

### Model Improvement
- Performed hyperparameter tuning
- Used cross-validation for KNN
- Pruned Decision Trees to reduce overfitting

### Model Evaluation
Compared models using:

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix
- ROC Curve

## Educational Purpose

This project was completed as part of my Machine Learning learning journey and was designed primarily for hands-on practice with classification algorithms.

The dataset used was a relatively small demonstration dataset intended for educational purposes. Therefore, the main objective was to understand the end-to-end machine learning workflow, compare different classification models, and gain practical experience with model tuning and evaluation techniques rather than achieving production-level performance.
