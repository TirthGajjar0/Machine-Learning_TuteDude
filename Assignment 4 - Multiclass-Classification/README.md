# Assignment 4 - Pollution Severity Classification

## Overview

This assignment focuses on classifying countries into different pollution severity categories (Low, Medium, and High) using machine learning classification algorithms.

The project covers the complete machine learning workflow, including data preprocessing, feature engineering, model training, hyperparameter tuning, and model evaluation.

## What I Did

### Data Preparation
- Cleaned and prepared the dataset
- Handled missing values and outliers
- Encoded categorical features
- Standardized and normalized numerical features

### Feature Engineering
- Created pollution-related indicators
- Applied feature scaling to pollution indices
- Analyzed energy consumption and pollution trends

### Machine Learning Models
Implemented and compared:

- Naive Bayes
- K-Nearest Neighbors (KNN)
- Decision Tree

### Model Improvement
- Performed hyperparameter tuning
- Used cross-validation for KNN
- Tuned Decision Tree parameters to reduce overfitting

## Model Performance Summary

| Model | Accuracy |
|---------|---------|
| Naive Bayes | 57.5% |
| K-Nearest Neighbors (KNN) | 80.0% |
| Decision Tree (Tuned) | 70.0% |

### Observations

- K-Nearest Neighbors (KNN) achieved the highest accuracy of 80.0% after hyperparameter tuning.
- Decision Tree achieved 70.0% accuracy and provided interpretable classification rules.
- Naive Bayes achieved 57.5% accuracy and served as a baseline probabilistic classifier.

### Key Takeaway

This assignment provided practical experience in comparing multiple classification algorithms on the same dataset. It demonstrated how model selection, hyperparameter tuning, and data characteristics can significantly influence predictive performance.
